# Contributing

1. Timing cores only. No seeker language.
2. RP and Shrike-fi pin maps must stay in the same commit if either changes.
3. RTL lives here and in shrike-edgekit. If you change a core, port it both ways
   or say why this repo diverged.
4. Every SLG47910 output needs `_oe`.
5. `make test-py` before a PR.
